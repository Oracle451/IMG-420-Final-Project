Slime Chronicles

A squishy 2D platformer where every sprite jiggles, squashes and ripples - powered by a custom C++ GDExtension for real-time soft-body deformation in Godot 4.

⬇ Windows ⬇ Linux ▶ Watch the demo

Rolling release - rebuilt automatically on every push to main.

See it wobble

The slime, the enemies, the UI and the environment all share one distortion system, so the whole game feels like jelly.

Meet DistortionSprite2D

The extension adds a new node type that deforms a sprite's mesh in real time - physics-aware, scriptable from C#, and tweakable right in the Inspector. Unlike shaders or pre-baked animation, it reacts to what's actually happening in the game.

🧲

Procedural deformation

Real-time vertex updates using spring-damper physics on a lattice.

🌊

Noise distortion

Perlin / Simplex noise gives natural idle wobble and ripple effects.

💥

Impulse response

Collision impacts propagate through the mesh for squash and stretch.

🧩

Custom node type

DistortionSprite2D extends Node2D for easy drop-in use.

🎛️

Editor parameters

Elasticity, damping, noise amplitude and speed, subdivision, texture.

#️⃣

C# API

Trigger impulses, set deformation states and freeze motion from code.

🧱

TileMap integration

Per-tile deformation without visible seams.
